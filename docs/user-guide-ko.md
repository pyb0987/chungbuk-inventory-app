# 충북사무소 재고관리 사용 안내

이 프로그램은 기존 엑셀 재고 파일 대신 사용하는 로컬 재고관리 프로그램입니다.
인터넷이나 별도 서버 없이, 실행한 컴퓨터 안에 데이터가 저장됩니다.

## 처음 실행

1. `ChungbukInventory.exe`를 실행합니다.
2. 작은 실행 창이 열리고 잠시 뒤 브라우저가 자동으로 열립니다.
3. 브라우저 주소는 보통 아래와 같습니다.

```text
http://127.0.0.1:5177/
```

실행 창을 닫거나 `Stop`을 누르면 프로그램도 같이 종료됩니다.

설치 위치가 Windows에서 보호되는 폴더라면 업데이트할 때 관리자 권한 확인 창이
나타날 수 있습니다. `예`를 누르면 설치 위치를 옮기지 않고 업데이트를 계속합니다.

`현황` 화면에서는 현재 합계, 파트실/개인차량/사무실 수량, 서울 입출고 수,
정상/삭제된 입출고 수, 백업 수, 최근 백업 정보를 볼 수 있습니다.

## 처음 재고 가져오기

처음 사용할 때는 현재 재고 엑셀 파일을 가져와야 합니다.

1. 왼쪽 메뉴에서 `가져오기`를 누릅니다.
2. `현재 재고 가져오기`에서 `재고현황 .xlsx 파일`을 선택합니다.
3. `모드`는 처음에는 `최초 가져오기`를 사용합니다.
4. `가져오기`를 누릅니다.
5. 가져온 뒤 `재고표`에서 품목별 수량이 맞는지 확인합니다.

같은 재고 파일을 실수로 다시 가져오면 중복 입력이 될 수 있으므로, 보통은
`같은 재고 다시 가져오기 허용`을 체크하지 않는 것이 좋습니다.

가져오기를 실행하면 프로그램이 가져오기 직전 상태를 백업 목록에 남깁니다.
가져온 결과가 잘못되었을 때는 `백업` 화면에서 해당 백업으로 되돌릴 수 있습니다.

`가져오기 기록`에서는 가져온 시간, 파일명, 상태, 가져온 행 수, 건너뛴 행 수,
새로 만든 품목/개인 수를 확인할 수 있습니다.

## 재고표 확인

`재고표` 화면에서 현재 재고를 한눈에 볼 수 있습니다.

- `파트실`: 파트실에 남아있는 수량
- 개인 이름별 칸: 각 개인이 가지고 있는 수량
- `사무실`: 사무실에서 사용하거나 보유 중인 수량
- `개인/사무실 합계`: 개인 보유분과 사무실 보유분의 합계
- `합계`: 파트실 + 개인 보유분 + 사무실 보유분

품목이 많을 때는 위쪽 `품목 검색`에 품목명을 입력해서 찾습니다.

`엑셀로 내보내기`를 누르면 품목, 파트실, 개인별 보유, 사무실,
개인/사무실 합계, 전체 합계를 포함한 `.xlsx` 파일을 저장할 수 있습니다.

## 입출고 입력

일상적인 재고 변경은 `입출고` 화면에서 입력합니다.

### 개인 출고

개인이 파트실 물건을 가져갈 때 사용합니다.

- 파트실 수량이 줄어듭니다.
- 선택한 개인의 보유 수량이 늘어납니다.

### 개인 반납

개인이 가지고 있던 물건을 파트실로 돌려줄 때 사용합니다.

- 선택한 개인의 보유 수량이 줄어듭니다.
- 파트실 수량이 늘어납니다.

### 서울로 반납

파트실에 있는 물건을 서울로 보낼 때 사용합니다.

- 파트실 수량이 줄어듭니다.
- 개인 선택은 필요하지 않습니다.

### 서울에서 파트실로 택배

서울에서 파트실로 물건을 받을 때 사용합니다.

- 파트실 수량이 늘어납니다.
- 개인 선택은 필요하지 않습니다.

### 사무실 사용/보유

파트실 물건을 사무실에서 사용하거나 보유할 때 사용합니다.

- 파트실 수량이 줄어듭니다.
- 사무실 수량이 늘어납니다.

### 입출고 수정/삭제/복원

잘못 입력한 입출고 기록은 `입출고 내역`에서 `수정`할 수 있습니다.

삭제는 완전히 지우는 것이 아니라 `삭제됨` 상태로 보관됩니다. 잘못 삭제했다면
같은 행의 `복원`을 눌러 되돌릴 수 있습니다.

복원할 때 현재 재고가 부족해 음수 재고가 되면 복원되지 않습니다.

## 품목 선택 방법

`입출고 입력`, `재고 조정`에서는 품목명을 검색해서 선택합니다.

1. `품목` 입력칸에 품목명 일부를 입력합니다.
2. 아래에 검색어가 포함된 품목 목록이 나타납니다.
3. 원하는 품목을 누르면 선택됩니다.

품목을 선택하지 않고 저장하면 저장되지 않습니다.

## 재고 조정

`재고 조정`은 일반 입출고가 아니라, 실사 차이 또는 오입력 수정처럼 직접
수량을 맞춰야 할 때만 사용합니다.

- `위치 = 파트실`: 파트실 수량을 직접 조정합니다.
- `위치 = 사무실`: 사무실 수량을 직접 조정합니다.
- `위치 = 개인`: 선택한 개인의 보유 수량을 직접 조정합니다.

`개인` 선택 칸은 `위치`가 `개인`일 때만 사용됩니다.

조정 수량은 늘릴 때 `1`, 줄일 때 `-1`처럼 입력합니다.

## 입출고 시리얼

시리얼이 필요한 물품은 `입출고 입력`의 `시리얼` 칸에 입력합니다. 시리얼이
필요하지 않은 입출고는 비워 두어도 됩니다.

입력한 시리얼은 `입출고 내역`에서 확인하고 검색할 수 있습니다. 잘못 입력했다면
해당 입출고 행의 `수정`을 눌러 시리얼을 고칠 수 있습니다.

## 입출고 내역 기간별 엑셀 저장

`입출고 내역` 오른쪽에서 시작일과 종료일을 선택하고 `기간 내역 엑셀로 내보내기`를
누르면 해당 기간의 기록만 엑셀 파일로 저장됩니다. 시작일과 종료일의 기록도 포함됩니다.
한쪽 날짜만 선택하면 그 날짜 이후 또는 이전 기록을 저장하고, 두 날짜를 모두 비우면 전체
입출고 내역을 저장합니다. 삭제된 기록도 `상태`가 `삭제됨`으로 표시되어 함께 저장됩니다.

## 품목/개인 추가와 비활성화

`입출고` 화면의 `품목/개인 등록`에서 새 품목이나 개인을 추가할 수 있습니다.

더 이상 쓰지 않는 품목이나 개인은 삭제가 아니라 `비활성화`됩니다. 기존 기록은
남아있고, 새 입력 목록에서만 빠집니다. 필요하면 다시 `복원`할 수 있습니다.

## 변경 기록

`기록` 화면에서는 재고 조정, 입출고 입력/수정/삭제/복원, 품목/개인 비활성화
같은 주요 변경 내역을 확인할 수 있습니다.

잘못 입력한 내용을 나중에 확인해야 할 때는 `기록 검색`에 품목명, 시리얼,
작업 종류, 메모 일부를 입력해서 찾습니다.

## 백업

프로그램은 하루에 한 번, 첫 데이터 변경 전에 자동 백업을 만듭니다.
필요하면 `백업` 화면에서 `백업 만들기`를 눌러 직접 만들 수도 있습니다.

백업 파일과 실제 데이터는
`C:\Users\Public\Documents\ChungbukInventory` 공용 폴더에 저장됩니다. 같은
컴퓨터의 Windows 사용자 계정들은 이 데이터베이스를 함께 사용합니다. 실제 사용을
시작한 뒤에는 이 폴더를 지우면 안 됩니다.

공용 데이터로 처음 전환할 때는 실제 데이터가 있는 Windows 계정에서 먼저
프로그램을 실행합니다. 다른 계정에도 별도의 기존 데이터베이스가 있으면 자동으로
덮어쓰지 않고 충돌 안내를 표시합니다. 두 파일을 모두 백업한 뒤 사용할
데이터베이스를 선택해야 합니다.

## 백업 복원

백업을 복원하면 현재 데이터가 선택한 백업 시점으로 바뀝니다.

백업 목록에 보이는 항목을 바로 복원할 때:

1. `백업` 화면으로 갑니다.
2. 백업 목록에서 원하는 항목의 `복원`을 누릅니다.
3. 확인창에서 계속 진행합니다.

백업 파일을 직접 골라 복원할 때:

1. `백업` 화면으로 갑니다.
2. `백업 복원`에서 백업 파일을 선택합니다.
3. `선택한 백업으로 복원`을 누릅니다.
4. 확인창에서 계속 진행합니다.

복원 전에는 자동으로 현재 상태 백업을 한 번 더 만듭니다.

## 전체 초기화

연습 중 입력한 모든 데이터를 지우려면 `백업` 화면 맨 아래의 `위험 작업`을 엽니다.

1. `전체 초기화 준비`를 누릅니다.
2. 모든 앱 데이터가 삭제된다는 확인란을 선택합니다.
3. `모든 데이터 삭제`를 누릅니다.
4. 마지막 확인창의 안내를 읽고 확인합니다.

품목, 개인, 재고, 입출고, 시리얼, 가져오기 기록과 변경 기록이 모두 삭제됩니다. 화면에서
바로 실행 취소할 수는 없습니다. 다만 프로그램이 초기화 직전 자동 백업 하나를 남기므로,
잘못 초기화했다면 백업 목록에서 해당 항목의 `복원`을 누를 수 있습니다.

## 현재 버전에서 아직 하지 않는 것

현재 버전은 기존 엑셀 양식 그대로 내보내기는 아직 구현하지 않았습니다.
현재 재고 가져오기, 재고 입력, 조회, 백업, 복원 기능을 먼저 사용할 수 있습니다.
