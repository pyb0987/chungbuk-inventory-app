# Windows 스모크 테스트

이 문서는 실제 사용 전 Windows PC에서 한 번 확인하기 위한 절차입니다.
아직 실제 재고 엑셀을 가져오기 전, 새로 압축을 푼 상태에서 진행하는 것이 좋습니다.

## 준비

1. `chungbuk-inventory-portable-release.zip`을 Windows PC에 복사합니다.
2. 원하는 위치에 압축을 풉니다.
3. 압축을 푼 폴더 안에 아래 파일이 있는지 확인합니다.

```text
START_CHUNGBUK_APP.cmd
ChungbukInventory.exe
VERIFY_CHUNGBUK_APP.cmd
runtime\node\node.exe
docs\user-guide-ko.md
user-data\
```

## 1. 사전 검증

`VERIFY_CHUNGBUK_APP.cmd`를 실행합니다.

성공 기준:

- `Verification passed.`가 표시됩니다.
- `node:sqlite: available`이 표시됩니다.
- `Fresh user-data folder: clean`이 표시됩니다.

실패하면 창에 표시된 내용을 개발자에게 전달합니다.

## 2. 앱 실행

`ChungbukInventory.exe`를 실행합니다.

성공 기준:

- 작은 실행 창이 열립니다.
- 브라우저가 자동으로 열립니다.
- 주소가 `http://127.0.0.1:5177/` 형태입니다.
- 화면 제목이 `충북사무소 재고관리`로 보입니다.
- `현황` 화면에 재고 요약과 `최근 백업` 영역이 보입니다.

## 3. 테스트 가져오기

가능하면 실제 파일을 넣기 전에 복사본으로 테스트합니다.

1. 왼쪽 메뉴에서 `가져오기`를 누릅니다.
2. `재고현황 .xlsx 파일`에서 재고현황 파일 복사본을 선택합니다.
3. `모드`는 `최초 가져오기`로 둡니다.
4. `가져오기`를 누릅니다.
5. `재고표`에서 품목과 수량이 보이는지 확인합니다.
6. `가져오기` 화면의 `가져오기 기록`에 방금 가져온 파일이 보이는지 확인합니다.

성공 기준:

- 오류 없이 가져오기가 끝납니다.
- `재고표`에 품목이 표시됩니다.
- `현황`의 `합계`, `파트실`, `개인차량`, `사무실` 값이 표시됩니다.
- `가져오기 기록`에 파일명, 상태, 가져온 행 수가 표시됩니다.

## 4. 기본 입력 테스트

테스트용 품목 하나로 아래를 확인합니다.

1. `입출고`에서 `개인 출고`를 저장합니다.
2. 같은 품목으로 `개인 반납`을 저장합니다.
3. `서울로 반납` 또는 `서울에서 파트실로 택배` 중 하나를 저장합니다.
4. `재고표`에서 수량이 예상 방향으로 바뀌는지 확인합니다.

성공 기준:

- `개인 출고`: 파트실 감소, 개인 증가
- `개인 반납`: 개인 감소, 파트실 증가
- `서울로 반납`: 파트실 감소
- `서울에서 파트실로 택배`: 파트실 증가

## 5. 백업 확인

1. `백업` 화면으로 갑니다.
2. `백업 만들기`를 누릅니다.
3. 백업 목록에 새 항목이 보이는지 확인합니다.
4. `현황` 화면으로 돌아가 `최근 백업`에 방금 만든 백업이 보이는지 확인합니다.

성공 기준:

- 백업 목록에 `created` 상태가 표시됩니다.
- `C:\Users\Public\Documents\ChungbukInventory\backups` 폴더 안에 백업 파일이 생깁니다.
- `최근 백업`에 백업 사유, 파일명, 시간이 표시됩니다.

## 6. 변경 기록 확인

1. `기록` 화면으로 갑니다.
2. 방금 입력한 입출고나 재고 조정 내역이 보이는지 확인합니다.
3. `기록 검색`에 품목명이나 작업 종류 일부를 입력해 검색합니다.

성공 기준:

- 입력, 수정, 삭제, 복원 같은 작업 종류가 한글로 표시됩니다.
- 품목명이나 작업 종류로 기록을 찾을 수 있습니다.

## 통과 후 안내

스모크 테스트가 끝난 뒤 실제 사용을 시작할 때는
`C:\Users\Public\Documents\ChungbukInventory` 폴더를 삭제하지 마세요.
이 공용 폴더에 실제 데이터베이스와 백업이 저장되며 두 Windows 계정이 함께 사용합니다.
