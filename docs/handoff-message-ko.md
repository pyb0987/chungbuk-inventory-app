# 요청자 전달 메시지

아래 내용을 프로그램 zip 파일과 함께 전달하면 됩니다.

```text
충북사무소 재고관리 프로그램 테스트본을 전달드립니다.

1. 첨부된 `chungbuk-inventory-portable-release.zip` 파일을 Windows 컴퓨터에 압축 해제해주세요.
2. 압축을 푼 폴더 안에서 먼저 `VERIFY_CHUNGBUK_APP.cmd`를 실행해주세요.
   - `Verification passed.`가 보이면 기본 실행 준비가 된 상태입니다.
   - 실패 메시지가 나오면 그 화면 내용을 보내주세요.
3. 그 다음 `ChungbukInventory.exe`를 실행해주세요.
   - 브라우저가 자동으로 열리고 `충북사무소 재고관리` 화면이 보이면 정상입니다.
4. 처음에는 `가져오기` 화면에서 현재 `재고현황 .xlsx` 파일을 가져와주세요.
5. 가져온 뒤 `재고표`에서 품목과 수량이 맞는지 확인해주세요.

테스트할 주요 기능은 아래입니다.

- 개인 출고: 파트실 수량이 줄고 개인 수량이 늘어나는지
- 개인 입고: 개인 수량이 줄고 파트실 수량이 늘어나는지
- 서울로 반납: 파트실 수량이 줄어드는지
- 서울에서 파트실로 택배: 파트실 수량이 늘어나는지
- 재고 조정: 실사 차이 조정이 가능한지
- 시리얼 등록/수정: 필요한 품목에 시리얼을 기록하고 고칠 수 있는지
- 변경 기록: 입력, 수정, 삭제, 복원 내용이 `기록` 화면에 남는지
- 백업 만들기: 백업 목록에 새 백업이 생기는지

주의사항:

- 실제 사용을 시작한 뒤에는 압축을 푼 폴더 안의 `user-data` 폴더를 삭제하면 안 됩니다.
- `user-data` 폴더에 실제 데이터베이스와 백업이 저장됩니다.
- 현재 버전은 기존 엑셀 양식 그대로 내보내기 기능은 아직 없습니다.

사용 중 헷갈리는 용어, 불편한 입력 방식, 수량이 예상과 다르게 바뀌는 경우가 있으면 알려주세요.
```
