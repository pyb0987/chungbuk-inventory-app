# 요청자 확인 체크리스트

실제 사용자가 Windows PC에서 확인할 항목입니다.

## 실행 확인

- [ ] `VERIFY_CHUNGBUK_APP.cmd` 실행 시 `Verification passed.`가 표시된다.
- [ ] `ChungbukInventory.exe` 실행 시 브라우저가 열린다.
- [ ] 화면 제목이 `충북사무소 재고관리`로 표시된다.
- [ ] `현황` 화면에 합계, 위치별 재고, 입출고/시리얼 수, 최근 백업 정보가 표시된다.

## 최초 가져오기

- [ ] `가져오기` 화면에서 현재 `재고현황 .xlsx` 파일을 가져올 수 있다.
- [ ] `재고표`에 품목이 표시된다.
- [ ] `합계`, `파트실`, `개인차량`, `사무실` 수량이 기존 엑셀과 비교해 납득된다.
- [ ] `가져오기 기록`에 파일명, 상태, 가져온 행 수가 표시된다.
- [ ] 같은 파일을 실수로 다시 가져오려 할 때 중복 방지 안내가 이해된다.

## 입출고 업무

- [ ] `개인 출고`: 파트실 수량이 줄고 선택한 개인 수량이 늘어난다.
- [ ] `개인 입고`: 선택한 개인 수량이 줄고 파트실 수량이 늘어난다.
- [ ] `서울로 반납`: 파트실 수량이 줄어든다.
- [ ] `서울에서 파트실로 택배`: 파트실 수량이 늘어난다.
- [ ] `사무실 사용/보유`: 파트실 수량이 줄고 사무실 수량이 늘어난다.
- [ ] 품목 검색 후 아래 목록에서 품목을 선택하는 방식이 이해된다.
- [ ] 잘못 입력한 입출고 내역을 수정할 수 있다.
- [ ] 입출고 삭제 전 확인창이 표시된다.
- [ ] 삭제된 입출고 내역을 `복원`할 수 있다.
- [ ] 음수 재고가 되는 입출고 복원은 저장되지 않는다.

## 재고 조정

- [ ] `위치 = 파트실` 조정이 가능하다.
- [ ] `위치 = 사무실` 조정이 가능하다.
- [ ] `위치 = 개인`일 때 개인 선택이 가능하다.
- [ ] 음수 재고가 되는 조정은 저장되지 않는다.

## 시리얼

- [ ] 품목별 시리얼을 등록할 수 있다.
- [ ] 시리얼 목록에서 검색할 수 있다.
- [ ] 잘못 입력한 시리얼을 수정할 수 있다.
- [ ] 시리얼 삭제 전 확인창이 표시된다.
- [ ] 삭제된 시리얼을 `복원`할 수 있다.
- [ ] 중복 시리얼 허용 방식이 업무에 맞다.

## 변경 기록

- [ ] `기록` 화면에서 입출고 입력/수정/삭제/복원 내역을 확인할 수 있다.
- [ ] `기록` 화면에서 시리얼 등록/수정/삭제/복원 내역을 확인할 수 있다.
- [ ] `기록 검색`으로 품목명, 시리얼, 작업 종류, 메모를 찾을 수 있다.

## 백업/복원

- [ ] `백업 만들기`를 누르면 백업 목록에 새 항목이 생긴다.
- [ ] `user-data\backups` 폴더에 백업 파일이 생긴다.
- [ ] `현황` 화면의 `최근 백업`에 방금 만든 백업이 표시된다.
- [ ] 백업 목록의 `복원` 버튼으로 해당 백업을 바로 복원할 수 있다.
- [ ] 복원 기능의 경고 문구가 이해된다.
